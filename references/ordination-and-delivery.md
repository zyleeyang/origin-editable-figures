# 降维图、椭圆和选图交付

## 数据与拟合

- 比较不同时间点/数据表示时确认相同样本、分组和特征集合，不同队列不强行配对。
- 说明输入是原始量、变换值、标准化值还是速率，以及实际公式。基线、空白校正和时间间隔以当前数据的方法说明为准，不从其他项目套用。
- 用户选定已有图后移除外框、改色、导出或拆图，复用坐标和样式。要求在新子集重新拟合时，重新标准化/拟合并记录软件版本、参数、种子及特征集合。
- PCA 轴标解释方差百分比；t-SNE/UMAP 轴只标维度，不编造解释方差。固定点的绘制顺序，避免遮挡改变使某组更突出。
- 比较同一方法的多个表示时使用相同参数。参数敏感性比较保留全部配置、使用一致评价口径；不能为达到期望排序分别挑种子、移动点、缩小椭圆或隐藏反例。
- 可统一同一方法各图的显示跨度和 x/y 数据单位，需容纳全部点与曲线。不同 t-SNE/UMAP 拟合的方向和全局距离并非天然可比较。
- “分得开”是分析结论，不能只依据二维图或椭圆。用户需要结论时回到原始特征，报告适用指标和不确定性；仅绘图时不擅加统计任务。

## “置信圈”的含义

数据椭圆、均值置信椭圆、预测区域不同。已有图/方法明确时保持一致；用户只说给点云加“95% 圈”时，可采用明确标注的 **95% 正态参考数据椭圆** 描述散布，并在图注说明它不是均值置信区间。不能把它当组间差异显著性。

需要复现 ggplot2 `stat_ellipse(type='norm', level=0.95)` 时，可使用其对应的二维构造：

```text
mu = 二维样本均值
S = 二维样本协方差（ddof=1）
c = 2 * F_quantile(0.95; 2, n-1)
边界：(z-mu)' inv(S) (z-mu) = c
```

若 `S = V diag(lambda) V'`，用半轴 `sqrt(c*lambda)` 和 V 生成边界。取 0 至 2π 共 361 个顶点，首末重合。该 F 缩放是具体实现，不是所有置信椭圆的通用公式。它没有将协方差除以 n；均值区域须用对应方法另算。

少于 3 个有限二维点或协方差退化时，不添加任意抖动强行画圈；保留散点并说明省略/退化。实际覆盖率未必恰为 95%，尤其 t-SNE/UMAP 点云未必近似正态。

保存中心、协方差、缩放系数、样本数和边界。每组曲线用独立 XY 列、同层原生 line plot，同组色、默认不填充。预计算边界能改样式，但散点数据变化后不会自动重算；需要动态更新时实现并验证重算机制。

依据：[ggplot2 stat_ellipse](https://ggplot2.tidyverse.org/reference/stat_ellipse.html)、[函数实现](https://raw.githubusercontent.com/tidyverse/ggplot2/main/R/stat-ellipse.R)。复现既有结果时固定实际版本，不默改为未来实现。

## 数据与交付布局

按规模采用，不要求小任务全部生成：

```text
输出目录/
  Main_independent_graphs.opju
  selected/                 按需提供选中单图 OPJU
  data/                     坐标、样本映射、配色和必要源数据
  previews/                 原生 PNG，按需 PDF/SVG
  选图.html                 批量选图时生成
  使用说明.md
  verification/             重开和数据核验
```

对照拼图仅作可选附加，不取代独立图页。只要三张独立 OPJU 时不再复制完整图集或重复压缩包。

图页/文件短名简洁稳定，长标题写方法/条件；维护“短名 → 方法、条件、分组、配置、样本数 → 数据表”的对应表。code1/code3 等含义查当前映射，不硬编码旧项目解释。

## HTML 选图页

- 本地静态 HTML、相对链接、不依赖 CDN，文件夹整体移动后仍能使用。
- 卡片显示图名、方法、条件、样本数和必要参数；预览可放大，可点击 OPJU/数据。确实存在导出文件时才提供 PNG/PDF/SVG 链接。
- 按配置/条件保留全部结果并提供筛选；用户选图不代表授权删掉未选图或隐藏反例。
- 引用本地图片，不同时内嵌 base64 副本占空间。
- 优先 Origin 原生预览；若另用绘图库生成则标明来源，并核对坐标、样本、配色、轴范围。
- 检查链接、中文文件名和交互脚本；有可用且合规的浏览器能力时检查布局。只做静态链接和 JS 语法检查时明确记录，不声称浏览器视觉验证已通过。

使用说明写清进入独立图页、修改对象、复制 OLE 的方法，以及预计算曲线是否自动更新。方法与结论只写当前数据实际支持的内容。
